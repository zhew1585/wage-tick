# 普通 App + 菜单栏常驻，不再是纯菜单栏工具

最初 App 是纯菜单栏工具 (`LSUIElement = YES`)：不出现在 Dock 和 ⌘Tab，今日概览是失去焦点就收起的无边框浮动面板，目标、历史、设置窗口也藏起了红绿灯。
问题是窗口一旦被别的 App 盖住，只能回到菜单栏小牛再点一次才找得回来，也没有主菜单，输入框连 ⌘V 都用不了。
Allen 决定 (2026-11-05) 改成普通 App，菜单栏小牛和数字照常常驻：

- 出现在 Dock 和 ⌘Tab，图标是彩色小牛 (`scripts/render-app-icon.swift` 生成 `AppIcon`)。
- 所有窗口都是标准窗口，带系统红绿灯，标题栏透明、内容铺满 (`WindowChrome`)；今日概览面板不再在失去焦点时收起，也不再浮在别的窗口上面。
- 所有窗口 (引导、今日概览、目标、历史、设置) 同一固定尺寸 360×560、不能拉伸，内容放不下时中间区域在窗口里滚动 (2026-11-05 起，`WindowMetrics`)。
  首次打开在鼠标所在屏幕正中，拖过之后记住位置 (`WindowPlacement`)；引导完成后今日概览接在引导窗口原位。
  只能拖顶部标题栏移动窗口：拖动空白处移动会抢走目标排队列表的拖动排序。
- 屏幕顶部有标准主菜单 (`MainMenu`)：「牛马鼓励器」(关于、设置、隐藏、退出)、「编辑」(撤销、剪切、复制、粘贴、全选)、「窗口」(最小化、关闭、今日概览 ⌘1、目标 ⌘2、历史 ⌘3)。
- 点 Dock 图标：已引导打开今日概览，未引导回到引导。
- 关掉所有窗口不退出，菜单栏小牛继续跑；只有「退出」(⌘Q) 才退出。

菜单栏小牛的左键菜单仍是所有入口的集合 (PRD F2、D10)，主菜单和 Dock 只是多了两条找回窗口的路。
左键菜单和主菜单一样用 macOS 原生菜单 (2026-11-05 起)：系统画标题、快捷键与勾选，不放图标，跟随系统深浅色。
代价是 Dock 里多一个图标；如果以后有人想改回纯菜单栏，先回到这条 ADR 重新权衡，而不是只把 `LSUIElement` 改回去。

补充 (2026-11-09)：设置里加了「隐藏 Dock 图标」开关，默认关，记在界面设置 `hidesDockIcon`。
开了就在运行时把激活策略切成 `.accessory` (`DockIcon`)，启动时也按它切：不进 Dock 和 ⌘Tab，屏幕顶部不显示主菜单。
`LSUIElement` 不动，窗口仍是标准窗口，主菜单照装，快捷键 (⌘V、⌘1 等) 照常可用；找回窗口只剩菜单栏小牛一条路，这是牛马自己选的。

补充 (2026-11-13，大胆版)：目标、历史、设置不再各开一个窗口，改成在今日概览窗口里像 iPhone 导航一样从右边推进来 (`PanelPage`、`View.pushed`)，返回或按 Esc 往右退回概览。
菜单栏左键菜单、主菜单「目标 ⌘2」「历史 ⌘3」「设置… ⌘,」、悬浮小牛右键都改为打开今日概览并直接推到那一页；页面内部 (历史的月份 → 日历 → 单日、目标的已到手与表单、概览的扣钱与请假表单) 也用同一个推入动画。
窗口只剩引导、今日概览与更新三个。
