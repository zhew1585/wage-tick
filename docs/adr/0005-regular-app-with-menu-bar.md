# 普通 App + 菜单栏常驻，不再是纯菜单栏工具

最初 App 是纯菜单栏工具 (`LSUIElement = YES`)：不出现在 Dock 和 ⌘Tab，今日概览是失去焦点就收起的无边框浮动面板，目标、历史、设置窗口也藏起了红绿灯。
问题是窗口一旦被别的 App 盖住，只能回到菜单栏小牛再点一次才找得回来，也没有主菜单，输入框连 ⌘V 都用不了。
Allen 决定 (2026-11-05) 改成普通 App，菜单栏小牛和数字照常常驻：

- 出现在 Dock 和 ⌘Tab，图标是彩色小牛 (`scripts/render-app-icon.swift` 生成 `AppIcon`)。
- 所有窗口都是标准窗口，带系统红绿灯，标题栏透明、内容铺满 (`WindowChrome`)；今日概览面板不再在失去焦点时收起，也不再浮在别的窗口上面。
- 屏幕顶部有标准主菜单 (`MainMenu`)：「牛马鼓励器」(关于、设置、隐藏、退出)、「编辑」(撤销、剪切、复制、粘贴、全选)、「窗口」(最小化、关闭、今日概览 ⌘1、目标 ⌘2、历史 ⌘3)。
- 点 Dock 图标：已引导打开今日概览，未引导回到引导。
- 关掉所有窗口不退出，菜单栏小牛继续跑；只有「退出」(⌘Q) 才退出。

菜单栏小牛的左键菜单不变，仍是所有入口的集合 (PRD F2、D10)，主菜单和 Dock 只是多了两条找回窗口的路。
代价是 Dock 里多一个图标；如果以后有人想改回纯菜单栏，先回到这条 ADR 重新权衡，而不是只把 `LSUIElement` 改回去。
