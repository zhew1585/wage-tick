# 日薪按本月应出勤日数计算，不用 21.75

日薪 = 月薪 ÷ 本月应出勤日数，所以每个月的日薪都可能不同 (2 月通常最高)。
没有采用 HR 和劳动法常用的 21.75 计薪天数，因为产品要的体感是"本月满勤正好拿到月薪"。
用 21.75 的话，本月累计在满勤时也会对不上月薪。
改这个口径会让所有历史结算的数字都变，所以不要随手"修正"成 21.75。

补充 (2026-11-09，issue #16)：按天算工资的人 (如实习生) 直接填日薪，不做这次除法。
只有应出勤日有钱，周末与法定节假日都是 0，所以按天时「满勤」等于应出勤天数 × 日薪，不再等于某个固定月薪。
按月与按天和金额一起按月记录 (`MonthlySalary.basis`)，旧数据读回为按月。
