# 后续版本想法

MVP 之外、已确认值得做但暂缓的想法。
做的时候可以用 `/to-tickets` 转成 GitHub issue。

## 平台

- iOS App，复用核心计算 Swift Package。
- iCloud / CloudKit 同步 macOS 与 iOS 的数据，不做自建后端。

## 工作制与日历

- 单休、大小周等非双休工作制。
- 跨零点班次 (夜班)，MVP 的计划下班时间最晚 23:59。

## 薪资

- 税前转到手：按社保、公积金、个税估算到手月薪。
- 加班费：白干时长可配置为按倍率计薪，而不是只用来吐槽。

## 鼓励与情绪反馈

- 成就系统 (比如连续满勤、本月零扣钱)。
- 分享卡片 (今日已赚、本月白干时长等生成图片)。
